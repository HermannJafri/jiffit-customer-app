# Jiffit Customer App

Expo + TypeScript customer app. Brand purple `#7C3AED`.

See [docs/workflows.md](./docs/workflows.md).

```bash
cp .env.example .env
npm install
npx expo start
```

Copy logos/splash from the Flutter reference app as listed in backend `docs/15-environment-assets.md`.
